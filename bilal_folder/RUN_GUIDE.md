# BUG HUNT 2026 — 14 TEAM RUN GUIDE

## Student preparation
Each team receives its `Student_Study_Pack` before the event. This is the correct working version.

## Event day
Give each team **only** its `Teacher_Event_Pack`. This is the buggy version students must debug.

## How students run the projects
- Python: `python server.py` (or `py server.py`)
- C: `gcc server.c -lws2_32 -o server.exe` then `server.exe`
- JavaScript: `node server.js`
- Open Chrome: `http://localhost:5000`

Every individual Student_Study_Pack and Teacher_Event_Pack contains its own `HOW_TO_RUN.md`.

## Teacher rule
Keep `ANSWER-KEY.md` inside Teacher_Event_Pack and do not distribute it to participants.
