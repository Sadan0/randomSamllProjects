# HOW TO RUN — JavaScript

### Requirements
- Node.js installed
- Google Chrome

### Steps
1. Open this folder in VS Code.
2. Open Terminal in this folder.
3. Run:

```bash
node server.js
```

4. Wait for the server to start.
5. Open Google Chrome.
6. Visit:

`http://localhost:5000`

### Stop the server
Press `Ctrl + C` in the terminal.
